# Household Power Consumption Forecasting

### تحلیل و پیش‌بینی مصرف برق خانگی با Prophet و SARIMA

تحلیل سری زمانی توان مصرفی برق خانگی، بررسی روند و الگوهای فصلی، و مقایسه دو مدل Prophet و SARIMA.

> Analyzes monthly average household active power, explores trends and seasonality, and compares Prophet and SARIMA forecasts using MAE, RMSE, and MAPE.

## قابلیت‌ها

- خواندن داده‌های توان مصرفی و مدیریت مقادیر گمشده با علامت `?`
- تبدیل تاریخ و ساعت به شاخص زمانی
- محاسبه میانگین ماهانه `Global_active_power`
- نمایش میانگین متحرک ۶ و ۱۲ ماهه
- تجزیه جمعی و ضربی سری زمانی و بررسی باقیمانده‌ها
- مدل‌سازی با Prophet و SARIMA با دوره فصلی ۱۲ماهه
- مقایسه مدل‌ها با MAE، RMSE و MAPE

## ابزارها

Python · pandas · NumPy · Matplotlib · statsmodels · Prophet · scikit-learn · Jupyter

## فایل اصلی

`power_consumption_time_series.ipynb`

## داده ورودی

فایل `household_power_consumption.txt` را کنار نوت‌بوک قرار دهید. کد از ستون‌های زیر استفاده می‌کند:

| ستون | کاربرد |
| --- | --- |
| `Date` | تاریخ با قالب روز/ماه/سال |
| `Time` | ساعت با قالب ساعت:دقیقه:ثانیه |
| `Global_active_power` | توان اکتیو مصرفی |

جداکننده فایل باید `;` باشد. فایل داده در این مخزن ارائه نشده است؛ استفاده و بازنشر آن تابع مجوز منبع داده است.

## روش ارزیابی و خروجی‌ها

۲۴ مشاهده ماهانه انتهایی برای آزمون کنار گذاشته می‌شوند و مدل‌ها روی بخش قبلی آموزش می‌بینند. خروجی شامل نمودارهای سری زمانی، مؤلفه‌های فصلی، پیش‌بینی‌ها و جدول مقایسه خطاها است.

مقادیر معیارها هنگام اجرای نوت‌بوک محاسبه می‌شوند. مقایسه مدل‌ها به داده و تقسیم زمانی همین آزمایش محدود است.

## محدودیت‌های نسخه فعلی

- متغیر هدف **میانگین ماهانه توان** است، نه مجموع انرژی مصرف‌شده در ماه.
- کنارگذاشتن ۲۴ ماه ممکن است داده آموزشی کمی برای برآورد فصل‌مندی سالانه باقی بگذارد.
- ارزیابی فعلی یک تقسیم زمانی ثابت است؛ اعتبارسنجی rolling-origin انجام نشده است.
- پیش‌بینی ۲۴گامی نمودار مقایسه مربوط به بازه آزمون است، نه آینده پس از انتهای کل داده‌ها.
